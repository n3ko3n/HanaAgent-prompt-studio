# 提示词工坊 prompt-studio

**一句话**：把你随手写的糙提示词，按档重写成模型更好执行的结构化提示词。改完就停在那儿，你要用才带走。

## 解决什么问题

顺手写下的提示词，问题通常不是"不礼貌"，而是"说不清"：要什么模模糊糊，做到什么算好没标准，模型只能猜。结果要么太泛，要么跑偏。

提示词工坊就做这一步——你说清楚要改成多重、要多细，它给你一版更明确的写法。

它的前提是：改写是你的决定，不是它的。优化结果**默认不写进对话历史**，只是停在输入框上方的一份草稿；你不点"复制"，它就没进过对话。会话状态、你的身份设定，默认一概不动。

## 三档，外加一个"接着改"

**基础优化** —— 改动最小。只消模糊，不套结构、不加装饰："写好看点"这类落不到地的说法，替它定成能核对的标准。

**专业优化** —— 把泛泛而谈钉到具体。加量化标准和明确边界，让每项要求都能被判断"做到没有"，但任务本身不换。

**步骤化规划** —— 把一段粗糙需求整理成结构化提示词，让接手的人拿着就能直接做、不用回头再问。该交代的（谁来做、手上已有什么、分几步、交付出什么）都要交代清楚，但怎么分节、标题怎么起，由任务本身定，不套固定模板。

**迭代改进** —— 不算第四档，是"拿一份已经能用的提示词，只按一条要求接着改"。你说改哪里，它只动那处，其余尽量原样保留。

几点补充：原文里的 {{变量占位符}} 原样保留；单次输入上限 8000 字；「附加角色设定」默认关闭，打开才在结果开头补角色定义，且只对基础/专业两档有意义（步骤化规划本就有角色段）。

## 两个入口

**输入框上方的常驻面板（✨）** —— 点输入栏的 ✨ 展开：写糙提示词、选档位、看结果、对着原文比差异，满意了点「复制」带走。历史记录也在这（本机，最多 50 条）。

**模型工具** —— 直接说"帮我优化这段提示词"，助手可显式调用 `prompt_studio_optimize` / `prompt_studio_open`。边界一致：只有显式调用时返回的文本才进上下文。

## 安装

从 Hana 扩展 / 市场安装，或用 Release 安装包。首次在「设置 → 扩展」按提示确认能力。应用自身不接触任何凭证与端点，模型调用走 Hana 宿主配置。宿主要求 Hana ≥ 0.1050.9，当前版本 0.4.0。
